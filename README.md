# Автоматизированное тестирование API Stellar Burgers

Проект содержит набор автоматизированных тестов для API сервиса доставки бургеров. Тесты проверяют основные сценарии работы с пользователями и заказами.

## Структура проекта

/
├── tests/
│   ├── test_create_order.py    # Тесты создания заказа
│   ├── test_get_orders.py      # Тесты получения заказов
│   ├── test_login.py           # Тесты авторизации
│   ├── test_registration.py    # Тесты регистрации
│   └── test_update_user.py     # Тесты изменения данных пользователя
│
├── data/
│   ├── __init__.py
│   ├── constants.py            # HTTP-коды, сообщения, ключи API
│   └── endpoints.py            # URL эндпоинтов
│
├── api_client.py               # API-клиент
├── conftest.py                 # Фикстуры pytest
├── helpers.py                  # Вспомогательные функции
├── requirements.txt            # Зависимости
└── README.md                   # Описание проекта



## Тестовые сценарии

1. **Регистрация пользователя** (`test_registration.py`)

* Создание уникального пользователя
* Попытка регистрации существующего пользователя
* Регистрация с незаполненными обязательными полями

2. **Авторизация** (`test_login.py`)

* Успешная авторизация
* Вход с неверным email
* Вход с неверным паролем
* Вход с пустыми данными

3. **Обновление данных пользователя** (`test_update_user.py`)

* Изменение имени, email и пароля (авторизованный пользователь)
* Попытка обновления без авторизации
* Проверка уникальности email при обновлении

4. **Создание заказа** (`test_create_order.py`)

* Заказ с авторизацией
* Заказ без авторизации
* Заказ с валидными ингредиентами
* Заказ без ингредиентов
* Заказ с невалидным хешем ингредиента

5. **Получение заказов** (`test_get_orders.py`)

* Получение списка заказов авторизованным пользователем
* Попытка получения без авторизации


## Архитектурные решения

* **API-клиент** (`api_client.py`) инкапсулирует все взаимодействия с API через класс `StellarBurgersAPI`

* **Фикстуры** (`conftest.py`) обеспечивают чистоту тестов и автоматическое удаление тестовых данных

* **Константы** (`constants.py`) содержат все необходимые HTTP-коды и сообщения об ошибках

* **Эндпоинты** (`endpoints.py`) централизованы в одном месте

* **Вспомогательные функции** (`helpers.py`) для генерации тестовых данных
